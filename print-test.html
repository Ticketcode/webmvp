Impresión ZPL desde el navegador

Envía una etiqueta ZPL a una Zebra ZQ510 mediante Zebra Browser Print, instalado en este PC.

Impresora: sin detectar
Antes de probar 1. Instale y abra Zebra Browser Print en este PC y empareje o conecte la ZQ510 (Bluetooth, USB o red).
2. Abra esta página desde http://localhost o desde una dirección https://; evite abrirla como archivo (file://).
3. La primera vez, abra https://localhost:9101/ssl_support y acepte el certificado.
